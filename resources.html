Computing infrastructure

Kimün

Local research server supporting docking, simulation, molecular analysis, data processing and GPU-accelerated computational workflows used by the laboratory.

  • Ubuntu server
  • Multi-core CPU
  • GPU acceleration
  • Large local storage

Configuration overview

Processor
2 × Intel Xeon Gold 6248R · 48 physical cores / 96 threads · 3.0 GHz base, up to 4.0 GHz
Memory
128 GiB RAM installed
Graphics
Dual NVIDIA GPU acceleration for compute-intensive workflows
Storage
≈ 28.3 TB raw local storage across NVMe and large-capacity disks
Operating system
Ubuntu 20.04.6 LTS (x86_64)
Connectivity
10 Gbit/s class interface reported in the hardware inventory

Typical uses

Kimün is used to centralize heavier computational tasks, including long-running batch jobs, molecular dynamics preparation, cheminformatics data processing, docking campaigns and GPU-assisted analyses. Its storage layout also makes it suitable for hosting project files and research datasets.

Computing infrastructure

Workstation II

Complementary local workstation reserved for analysis, software development, auxiliary data processing and computational chemistry support tasks.

  • Analysis node
  • Software development
  • Cheminformatics support

Role in the laboratory

Workstation II acts as a second compute seat to distribute interactive workloads across the laboratory. It is intended to support cheminformatics analyses, manuscript preparation, visualization tasks, scripting and general software development activities associated with the group’s projects.

Its full hardware inventory can be expanded in future updates as the infrastructure registry grows.

Supported workflows

  • Structure preparation and visualization
  • Cheminformatics pipelines and scripting
  • Data curation and local analysis
  • Support for software development and testing

High-performance computing

NLHPC

The National Laboratory for High Performance Computing of Chile provides access to advanced computational resources for larger-scale simulations and analysis pipelines.

  • National infrastructure
  • Large-scale simulation
  • Batch processing
  • Research computing

How it supports SB²CS

NLHPC extends the laboratory’s local infrastructure when projects require more computational throughput, distributed execution or larger resource allocations than local equipment can provide.

  • Large molecular dynamics and simulation workloads
  • Longer or parallelized batch calculations
  • Scalable compute for data-intensive research stages

Institutional context

The laboratory acknowledges NLHPC as a strategic external platform that complements Kimün and the laboratory’s workstations, especially in computational campaigns with elevated demand.
